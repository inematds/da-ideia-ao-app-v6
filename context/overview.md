# Visão geral

Curso v6 em português para aprender a desenvolver com IA. 24 aulas em 6 módulos; organizador pessoal de demandas como exemplo. Fonte: entrevista fornecida pelo usuário; desenvolvimento autoral.

A aplicação usa somente armazenamento do navegador. As aulas sobre permissões são exercícios de análise para uma versão futura, sem apresentar a aplicação pessoal como sistema multiusuário.
