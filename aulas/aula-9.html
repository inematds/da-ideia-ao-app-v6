1A interface recebe a ação

Interface é a parte que você vê e usa. Ela mostra campos, botões e mensagens. Uma interface pode validar campos, mas essa validação sozinha não protege serviços compartilhados.

Lúcia vê uma mensagem ao tentar cadastrar um título vazio.

2A lógica aplica as regras

Lógica é o conjunto de regras que transforma ações em resultados. No nosso treino, ela roda no navegador. Numa aplicação compartilhada, regras de acesso precisam ser impostas por uma parte confiável.

Rafael define que concluir uma demanda deve mudar sua situação, sem apagar o título.

3O armazenamento conserva registros

Armazenamento é onde a informação permanece. O navegador pode guardar dados locais. Um banco de dados compartilhado atende necessidades diferentes e exige regras de acesso.

Lúcia percebe que a lista do computador não aparece automaticamente no celular.
