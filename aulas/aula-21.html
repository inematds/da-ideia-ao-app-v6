Publique uma demonstração com limites visíveis

Você consegue preparar uma versão de demonstração e uma conferência de publicação.

Publicar coloca os arquivos ao alcance de outras pessoas. Uma demonstração precisa dizer o que faz e onde seus dados ficam.

Em 1 minuto

  1. Publique só os arquivos previstos.
  2. Explique os limites da demonstração.
  3. Teste como visitante.

1Escolha exatamente o que vai publicar

Uma página estática entrega arquivos ao navegador. Ela atende ao nosso aplicativo local. Não transforma automaticamente a lista numa aplicação compartilhada.

Lúcia compartilha a demonstração e avisa que cada navegador terá registros próprios.

2Prepare uma versão identificada

Git registra versões dos arquivos. GitHub hospeda repositórios, que são conjuntos de arquivos e seu histórico. GitHub Pages pode servir os arquivos de um site estático.

Rafael guarda a versão testada antes de torná-la acessível.

3Confira o endereço como visitante

Abra a publicação numa janela privada, sem outras sessões privadas abertas. Essa é a janela limpa usada neste teste. Confira imagens, navegação e o caminho principal. Não use só a tela do editor como prova de que o site publicado funciona.

Lúcia abre a demonstração num navegador separado e cadastra uma demanda fictícia.

Teste-se

A demonstração abriu para duas pessoas. Isso prova colaboração?

Se travou aqui, é normalVocê pode estudar a publicação usando a demonstração deste curso. Criar sua própria conta e configurar hospedagem fica no aprofundamento.

Conferir a referência da análise

Publicar apenas os arquivos da demonstração; excluir credenciais e cópias privadas. Informar dados locais e ausência de colaboração. No endereço publicado, conferir abertura, cadastro, filtro, conservação e recuperação.

Para ampliar o raciocínio

Publicação guiada pelo navegador: crie um repositório público vazio na sua conta GitHub; envie somente os arquivos de demonstração; registre a alteração. Em Settings → Pages, escolha a origem por branch e a pasta raiz, quando essa opção estiver disponível. Aguarde o endereço informado pela plataforma e faça os testes. A disponibilidade depende da conta e da configuração; se a tela diferir, consulte a ajuda oficial do GitHub Pages. Nunca envie credenciais. Não há necessidade de contratar serviços de IA por API para hospedar esta demonstração.
